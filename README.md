📌 PasteApp

PasteApp is a simple, clean, and intuitive web application built with React and Vite that lets you create, save, and share text/code snippets quickly — just like a lightweight pastebin service. It’s ideal for sharing code, notes, snippets, and text with friends, teammates, or for personal use.

👉 Live Demo: https://paste-app-two-omega.vercel.app


🚀 Features

✔ Create new pastes/snippets with ease

✔ Syntax highlighting support

✔ Responsive UI with modern styling

✔ Fast performance powered by React + Vite


🧱 Tech Stack

This project uses:

Technology and Purpose

React	UI library for component-based frontend

Vite	Fast development server + build tool

HTML/CSS/JavaScript	UI markup, styling & logic


📦 Getting Started

These instructions help you run PasteApp on your local machine for development and testing.

🧠 Prerequisites

Make sure you have this installed:

✔ Node.js (v14 or higher)

✔ npm


💻 Installation

# Clone the repo

git clone https://github.com/Meet-Patel-12/PasteApp.git

# Navigate to the project

cd PasteApp

# Install dependencies

npm install

🛠️ Run Locally

To start the development server:

npm run dev


📦 Build for Production

To bundle the app for production deployment:

npm run build

📁 Deployment

You can deploy PasteApp to services like:

🚀 Vercel (recommended)

📦 Netlify

☁️ Firebase Hosting

📦 GitHub Pages (if SPA with redirect support)

Example: To deploy with Vercel (if not already):

npm i -g vercel

vercel
